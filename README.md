This is an addon for the **Touhou Little Maid** mod. It adds several new variants of the "Substitute Jizo", giving players more control over their maid's invulnerability state.

## 📦 New Content

- **Reverse Substitute Jizo**  
  Use it on a maid that is already invulnerable to **remove her invulnerability**. Useful when you want your maid to participate in combat or take damage again.

- **Repeated (Reverse) Substitute Jizo**  
  A Substitute Jizo that can be **used multiple times** without being consumed (or reusable), making it convenient to toggle a maid's invulnerability repeatedly.

## 🎯 Purpose

- Allows players to freely control whether a maid is invulnerable.
- Provides more options for modpack authors to create quest rewards or crafting recipes.
- Adds more fun and strategy to maid gameplay.

## 🔧 Installation

1. Make sure the **Touhou Little Maid** mod is installed.
2. Place the `.jar` file of this mod into the `.minecraft/mods` folder.
3. Launch the game.

## ⚠️ Requirements

- **Minecraft Versions**: 1.21.1
- **Required Mod**: [Touhou Little Maid](https://www.curseforge.com/minecraft/mc-mods/touhou-little-maid)

# 车万女仆：替身地藏拓展

[![可在 GitHub 上获取](https://wsrv.nl/?url=https%3A%2F%2Fcdn.jsdelivr.net%2Fnpm%2F%40intergrav%2Fdevins-badges%403%2Fassets%2Fcozy%2Favailable%2Fgithub_vector.svg&n=-1) ](https://github.com/Steven23334/TLM-Substitute-Jizo-Expand)
[![适用于车万女仆](https://cdn.modrinth.com/data/cached_images/ea5dc160571134bd0ea89ac52075b542fb331e46_0.webp)](https://modrinth.com/project/R0bDWFAW)  

这是一个为 **车万女仆 (Touhou Little Maid)** 模组开发的拓展，添加了多种新的“替身地藏”变体，让玩家可以更灵活地控制女仆的无敌状态。

## 📦 新增内容

- **反替身地藏 (Reverse Substitute Jizo)**  
  对已经处于无敌状态的女仆使用，可以**解除其无敌状态**。适合在需要女仆重新参与战斗或受到伤害时使用。

- **多次性（反）替身地藏 (Repeated Substitute Jizo)**  
  可以**多次使用**的替身地藏，使用后不会消耗（或可重复使用），方便反复切换女仆的无敌状态。

## 🎯 模组用途

- 让玩家可以自由控制女仆是否无敌。
- 为整合包作者提供更多任务奖励或合成配方的选择。
- 增加女仆玩法的趣味性和策略性。

## 🔧 安装方法

1. 确保已安装 **车万女仆 (Touhou Little Maid)** 模组。
2. 将本模组的 `.jar` 文件放入 `.minecraft/mods` 文件夹。
3. 启动游戏即可。

## ⚠️ 前置要求

- **Minecraft 版本**：1.21.1
- **必需模组**：[车万女仆 (Touhou Little Maid)](https://www.curseforge.com/minecraft/mc-mods/touhou-little-maid)
